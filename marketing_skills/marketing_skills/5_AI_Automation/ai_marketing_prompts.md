# AI Marketing Prompt Library

## 📢 Prompt for Facebook Ad Targeting
```
You are a senior Facebook Ads specialist for a real‑estate company.
Create a detailed targeting specification for a campaign that promotes high‑end apartments in District 2, targeting:
- Age 30‑55, incomes above 30M VND.
- Interests: Real‑estate investment, luxury lifestyle, travel, finance.
- Behaviors: Frequent travelers, recent home‑search activity.
Return the result as JSON with keys `age_min`, `age_max`, `genders`, `interests`, `behaviors`.
```

## ✍️ Prompt for Real‑Estate Content (AIDA)
```
Write a 120‑word Facebook post promoting a new residential project "Tecco Felice Homes" in Ho‑Chi Minh City.
Use the AIDA framework (Attention, Interest, Desire, Action). Include a clear CTA to book a visit via Zalo.
Tone: modern, minimal, premium. Mention price starting from 5 billion VND.
Output only the final copy, no explanations.
```

## 📊 Prompt for Market Research Summary
```
Summarize the latest market trends for residential real‑estate in Ho Chi Minh City based on the last 3 months of news articles.
Provide bullet points on:
- Average price per m² by district.
- Upcoming zoning changes.
- Top 3 competitors in District 2.
Keep the summary under 150 words.
```

## 🔍 Prompt for SEO Keyword Cluster
```
Generate a list of 10 long‑tail keywords for a blog post about "buying a condo in District 2".
Include search volume (rough estimate) and difficulty score (0‑100).
Format as a markdown table with columns: Keyword, Volume, Difficulty.
```

## 🤖 Prompt for AI Automation (Workflow Skeleton)
```
Create a step‑by‑step outline for an automated workflow that:
1. Receives a keyword from a Google Sheet.
2. Uses a web‑search tool to fetch latest market data.
3. Generates a 400‑word article using the AIDA copywriting style.
4. Publishes the article to WordPress as a draft.
Provide the outline as a numbered list.
```
